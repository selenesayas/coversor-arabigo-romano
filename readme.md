#  Conversor de Números Arábigos ↔ Romanos

Este proyecto permite convertir números **arábigos a romanos** y **romanos a arábigos** de forma bidireccional.  
Incluye pruebas automáticas con **Jest** y está preparado para ser desplegado en **Vercel** o **Netlify**.


# Funcionalidades

- Conversión **de número arábigo a romano** (ejemplo: `1994 → MCMXCIV`)
- Conversión **de número romano a arábigo** (ejemplo: `XLVII → 47`)
- Validación de errores:
  - Números fuera del rango `1–3999`
  - Números con decimales
  - Entradas vacías o no válidas
  - Romanos incorrectos
